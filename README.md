# 「世界之巅」竞猜球员伤病参考

手机优先的 NBA 次日球员伤病参考。固定网页使用 GitHub Pages，默认按北京时间显示次日比赛。

- 中文球员名、中文伤情，两队伤病上下排列。
- 每小时自动获取赛程与参赛球队伤病，构建并发布，访问地址保持不变。
- 最新伤病来自媒体名单，不等于本场最终出场确认；来源、报告时间和旧数据提示在页面保留。
- 网络来源失败时使用有原时间标记的缓存，不会显示“全员健康”。

## 源码

`dashboard-source.zip` 是本仓库部署的完整源码包，解压后为 `dashboard/`：

- `scripts/update.py`：自动抓取、北京时间匹配、缓存与中文名归一化。
- `config/players.zh.json`：可维护的中文球员名。
- `web/`：页面模板、样式和交互。
- `tests/test_update.py`：12 项日期、降级、中文名等回归测试。
- `requirements.txt`：Python 依赖。

GitHub 连接暂未获此新仓库写权限，因此首次通过网页上传源码包。修改源码时解压编辑，再以同一目录结构重新压缩替换；提交即自动构建。

## 自动发布

根目录 `.github/workflows/update.yml` 为实际执行入口：解压源码、安装依赖、测试、恢复最近快照、获取数据、每日保存持久快照并发布 Pages。每小时第 17 分钟运行（UTC，北京时间同为每小时第 17 分钟）；GitHub 调度可能延迟，不保证分钟级及时性。

每天提交一次快照，保持仓库活动并保留恢复数据。更多时段使用 Actions 缓存。抓取和部署失败不会自动把错误页面伪装成成功新数据。

公众号菜单应使用 Pages 的固定首页地址，而非 GitHub 仓库页、Actions 产物或带日期的文件。实际网址见 Settings → Pages。

GitHub Pages 从不同运营商、微信内置浏览器的访问情况需在真实手机验证；没有大陆地区可用性或服务 SLA 保证。若后续使用自有域名，可以保持菜单地址并迁移托管。
